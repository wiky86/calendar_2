# 유비온 일정 스튜디오

2026-10-17 최신 배포본. 기존 기수 가져오기, 2027년 휴일, 전체 기간 시간표 포함.

## GitHub Pages 배포

1. ZIP 압축을 풀고 파일들을 저장소에 업로드합니다. ZIP 자체가 아니라 index.html, app.js, style.css가 저장소 최상위에 위치해야 합니다.
2. Settings → Pages → Source에서 Deploy from a branch를 선택합니다.
3. 업로드한 브랜치(main 또는 master)와 /(root)를 선택해 저장합니다.
4. 배포 완료 후 Pages에 표시되는 주소를 엽니다.

별도 npm 설치, 빌드, API 키, 서버가 필요하지 않습니다. 기존 저장소를 사용한다면 먼저 백업하고 세 파일을 함께 교체하세요. 이전 Firebase·Google 연동 파일은 이 버전에서 참조하지 않습니다.

## 데이터 이전

데이터는 브라우저 localStorage에 저장되므로 새 주소로 자동 이전되지 않습니다.
현재 일정 스튜디오에서 ‘백업 다운로드’로 JSON을 받은 뒤, 새 사이트의 ‘백업 / 기존 데이터 가져오기’로 불러오세요. 가져오기는 해당 사이트의 기존 데이터를 교체합니다.
코드 ZIP에는 실제 운영 데이터가 포함되어 있지 않습니다. 첫 실행 시 예시 데이터가 표시되며 ‘새 일정으로 시작’으로 비울 수 있습니다.

## 파일

- index.html: 화면 구조
- style.css: 디자인·반응형 스타일
- app.js: 일정 계산과 전체 기능
- .nojekyll: 정적 파일 배포 설정
- tests/schedule.test.cjs: Node.js 로직 검증

## 기능 및 범위

기수별 전체 흐름(3개월·6개월·전 기간), 월별/전 기간 시간표, 강사 필터·중복 감지, 기수 추가·수정·삭제·복제·정보 가져오기, 수업 요일·교육시간 설정, 휴일 관리, JSON 백업·가져오기, 전체 CSV 출력을 제공합니다.

기기 간 서버 동기화, 구글 시트 전송, XLSX 출력은 미구현입니다. 경과율은 예정 수업일 기준으로 실제 출석·이수율이 아닙니다. 하루 한 과목·한 강사 기준입니다.
Google Fonts를 외부에서 불러오며 연결되지 않으면 시스템 글꼴을 사용합니다.

## 로컬 실행 및 검증

폴더에서 `python -m http.server 8000`을 실행하고 http://localhost:8000 에 접속합니다.
Node.js 18 이상에서 `node tests/schedule.test.cjs`로 로직 검증을 실행할 수 있습니다. 브라우저 시각 검증은 별도입니다.

## 기수 관리 개선

왼쪽의 기수 관리에서 추가·수정·복제·삭제를 바로 실행할 수 있습니다. 기수명·과목·강사 검색과 상태 필터를 지원합니다. 위·아래 버튼으로 표시 순서를 바꾸면 시간표에도 반영됩니다. 마지막 삭제는 같은 페이지를 연 상태에서 되돌릴 수 있으며 새로고침 후에는 복원 정보가 사라집니다. 복제는 입력창만 준비하고 저장해야 새 기수가 생성됩니다.
